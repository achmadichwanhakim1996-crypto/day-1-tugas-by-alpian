. pwd (Print Working Directory)
	• Fungsi: Menampilkan direktori/folder aktif tempat Anda berada saat ini.
2. ls (List)
	• Fungsi: Menampilkan daftar file dan folder di dalam direktori saat ini.
3. cd (Change Directory)
	• Fungsi: Berpindah dari satu direktori ke direktori lain.
4. mkdir (Make Directory)
	• Fungsi: Membuat folder baru di dalam direktori aktif.
5. cp (Copy)
	• Fungsi: Menyalin file atau direktori dari satu lokasi ke lokasi lain.
6. mv (Move)
	• Fungsi: Memindahkan file/direktori atau mengganti nama (rename) file.
7. rm (Remove)
	• Fungsi: Menghapus file atau direktori (gunakan dengan hati-hati karena sifatnya permanen).
8. cat (Concatenate)
	• Fungsi: Menampilkan isi dari suatu file teks langsung di terminal.
9. df (Disk Free)
	• Fungsi: Menampilkan informasi kapasitas dan penggunaan ruang penyimpanan (disk space) pada sistem.
10. top (Table of Processes)
	• Fungsi: Menampilkan daftar proses sistem yang sedang berjalan secara real-time beserta penggunaan CPU dan memori.

2.
Package Manager adalah sekumpulan alat (tools) atau sistem perangkat lunak yang berfungsi untuk mengotomatisasi proses instalasi, pembaruan (upgrade), konfigurasi, dan penghapusan (uninstall) perangkat lunak pada sistem operasi Linux.
Keunggulan utama menggunakan package manager adalah kemampuannya dalam mengelola dependensi (pustaka atau komponen pendukung lain yang dibutuhkan oleh suatu aplikasi) secara otomatis tanpa harus mengunduhnya secara manual.
